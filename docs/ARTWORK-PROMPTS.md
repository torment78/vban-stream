# VBAN Stream artwork editing prompts

Edited with the built-in imagegen tool. Each image is a separate text-only edit of the corresponding existing banner. PNG masters and JPEG exports are in `docs/images`.

## wide-tagged

```text
Use case: text-localization.
Asset type: wide horizontal product banner.
Input image: the sole attached image is the exact edit target, not a style reference.
Primary request: Rename this product from VBAN Audio to VBAN Stream. Change ONLY the large white word "AUDIO" to "STREAM" (S-T-R-E-A-M) immediately beneath "VBAN". Keep the same bold white type style, height and alignment; allow the new word to be wider to fit the extra letter cleanly within the existing title area.
Strict invariants: keep the exact existing canvas dimensions and aspect ratio, crop, layout, cyan arrow-ring waveform logo, two amber nodes, electronic lines, lighting, colors, background and every other word and credit unchanged. The large title must read "VBAN" on its first line and "STREAM" on its second line. Keep "8 inputs · 2 monitor returns", "Windows x64 | OBS Studio", and "by ElkaSoft" exactly as shown. Keep the small bottom-right VOICE MEETER badge and the caption 'VBAN protocol by VB-Audio' exactly as shown.
No redesign, no new elements, no movement of the logo or other text, no additional tagline. Output just this one edited banner at full quality.
```

## 0.3.5 feature update

Built-in imagegen edits, one call per existing PNG. Each output is saved beside its input with `-0.3.5` before the extension. Full-resolution JPEG exports use quality 92 and are all below 1,000,000 bytes. The original PNGs and JPEGs are preserved.

### wide-tagged — 0.3.5

Input: `docs/images/wide-tagged.png`

Output: `docs/images/wide-tagged-0.3.5.png`

```text
Use case: text-localization.
Input image: the supplied image is the exact edit target, not a style reference.
Primary request: update ONLY the cyan feature text to exactly TWO rows, retaining the existing design.
Row 1, exact text: "8 audio inputs • 2 monitor returns"
Row 2, exact text: "2 VBAN Frame inputs • 2 mouse remotes • 1 VBAN Frame output"
Use the existing cyan sans-serif treatment. The first row may be slightly smaller than the old single feature row so it fits. The second row should be a clean smaller supporting line, all on ONE line with generous readable spacing, directly beneath the first. Keep both rows within the existing feature-text area above the compatibility line. No wrapping into a third feature row. No added panel or box.
Strict invariants: preserve the exact existing canvas/aspect ratio, dark navy background, all electronic circuit lines and cyan/amber waves if present, depth/glows/lighting, cyan circular waveform-and-arrows logo with two amber nodes, large white VBAN STREAM title, and "by ElkaSoft" attribution. Do not redraw, restyle, move, recolor or replace any logo or background. Preserve all other existing text exactly. Do not add version numbers, marketing slogans, new badges, or icons. Output one full-quality edited banner.
This is the horizontal banner. Left-align the feature rows beneath STREAM, matching the original alignment.
Keep the existing bottom-right VOICE MEETER badge and "VBAN protocol by VB-Audio" caption intact.
Preserve the existing compatibility line "Windows x64 | OBS Studio" unchanged.
```
